- Status: Approved by user for implementation, revision 3.
- Goal: explore a local project through an interactive static snapshot.
- Scope: overview, architecture, documentation, tests and code health; responsive desktop-first layout.
- Overview is titled Metrics; explanatory headings, branding, sidebar status and footer are omitted.
